# 🏋️‍♂️ VITALFIT – Administrative Dashboard

VITALFIT Dashboard es una aplicación web administrativa construida con **Next.js**, diseñada para gestionar una cadena de franquicias de gimnasios.  
Permite a los administradores controlar sucursales, usuarios, clientes, membresías, reportes y KPI operativos/financieros.

Este proyecto forma parte del desarrollo académico de Ingeniería en Informática (UCLA).

---

## 🚀 Características Principales

- Gestión de sucursales (CRUD)
- Gestión de usuarios administrativos y roles
- Gestión de clientes, membresías y pagos
- Dashboard ejecutivo con KPIs
- Reportes descargables (ventas, clientes, clases, finanzas)
- Integración con API REST
- Autenticación basada en JWT
- Diseño responsive y moderno (TailwindCSS)
- Ramas dedicadas para Producción y Staging

---

## 📦 Tecnologías Utilizadas

- **Next.js 14 (App Router)**
- **React**
- **TailwindCSS**
- **TypeScript**
- **Axios**
- **Node.js / NPM**
- **Vercel** para despliegue
